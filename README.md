# Automotive Driving Robot
University of Southampton (FEEG6013) group design project: a robot that operates a vehicle's pedals, with closed-loop motor control and pedal/throttle position sensing.
- `Closed_Loop_Motor/`, `closedLoop_v2/`, `CLEAN_Closed_Loop_Motor/` – closed-loop motor control
- `openLoop_v1/` – open-loop control
- `Pedal_and_Pot_Pos_Read/`, `pedalPosRead/` – position sensing
- `Sys_Ident/` – system-identification test signals (PRBS, steps, sine, random)
- `Callibration_and_Limits/`, `Combo_*/` – calibration & test profiles

This was a team project; shared with the group's permission.
